# Dataset

This project uses the **Job Description Dataset** available on Kaggle.

## Dataset Source

[Kaggle - Job Description Dataset](https://www.kaggle.com/datasets/ravindrasinghrana/job-description-dataset)

## Dataset Description

The dataset contains approximately 78,705 job postings with 23 columns.

Important fields used in this project include:

- Job Title
- Role
- Qualifications
- Job Description
- Skills
- Responsibilities
- Experience
- Work Type
- Location

## Usage in This Project

The dataset is used as the source of job postings for the NLP-based resume–job matching system.

The resume used by the system is provided as text input by the user or as a synthetic test resume.

The dataset does **not** contain verified resume–job matching pairs or ground-truth relevance labels.

The original dataset should be downloaded from Kaggle rather than stored directly in this repository.
